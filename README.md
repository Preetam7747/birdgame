# 🐦 Bird Jumping Game

A simple bird jumping game made with HTML, CSS, and JavaScript.

## 🎮 How to Play

Press **SPACE** to make the bird jump.

Avoid the pipes and try to get the highest score.

## 📁 Files

- `index.html`
- `style.css`
- `game.js`

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ▶️ How to Run

Open `index.html` in your web browser.
